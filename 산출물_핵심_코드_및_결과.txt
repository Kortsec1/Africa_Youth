1. SNI 기반 정책 설정 파일 (configs/policy.yaml)
================================================================================

정책 파일 구조: YAML 형식으로 기본 정책과 SNI별 규칙 정의

default_action: block
upstream:
  host: 127.0.0.1
  port: 8443
rules:
  - sni: allowed.test
    action: allow
    reason: 허용된 로컬 테스트 도메인
  - sni: blocked.test
    action: block
    reason: 차단 동작 확인용 로컬 테스트 도메인

설명:
- default_action: 정책에 없는 SNI에 대한 기본 동작 (block)
- upstream: 정책이 allow인 경우 중계할 로컬 서버 주소
- rules: SNI별 allow/block 규칙 목록

2. SNI 파서 핵심 알고리즘 (proxy/sni_parser.py)
================================================================================

ClientHello 구조 분석:

1. TLS Record Header (5바이트)
   - Byte 0: Content Type (0x16 = Handshake)
   - Byte 1-2: TLS Record Version
   - Byte 3-4: Record Length (big-endian)

2. Handshake Body
   - Byte 0: Handshake Type (0x01 = ClientHello)
   - Byte 1-3: ClientHello Length (big-endian)
   - Byte 4+: ClientHello Payload

3. ClientHello Payload 구조
   - Byte 0-1: TLS Version
   - Byte 2-33: Random (32바이트)
   - Byte 34: Session ID Length
   - 이후: Session ID
   - 이후: Cipher Suites Length (2바이트)
   - 이후: Cipher Suites
   - 이후: Compression Methods Length
   - 이후: Compression Methods
   - 이후: Extensions Length (2바이트)
   - 이후: Extensions

4. Extensions 구조 (SNI 찾기)
   각 Extension:
   - Byte 0-1: Extension Type (0x0000 = SNI)
   - Byte 2-3: Extension Length
   - 이후: Extension Data
   
   SNI Extension Data:
   - Byte 0-1: Server Name List Length
   - Byte 2: Name Type (0x00 = host_name)
   - Byte 3-4: Name Length
   - 이후: Domain Name (IDNA 인코딩)

SNI 추출 함수 (파이썬 의사코드):

def extract_sni(data: bytes) -> str | None:
    # 1. TLS record header 검증
    if len(data) < 5:
        raise ParseError("incomplete header")
    
    # 2. Content Type 확인 (0x16 = Handshake)
    if data[0] != 0x16:
        raise ParseError("not a handshake record")
    
    # 3. Record Length 읽기
    record_len = int.from_bytes(data[3:5], "big")
    
    # 4. 전체 record 확인
    if len(data) < 5 + record_len:
        raise ParseError("incomplete record body")
    
    # 5. ClientHello 확인 (0x01)
    body = data[5:5+record_len]
    if body[0] != 0x01:
        raise ParseError("not a ClientHello")
    
    # 6. ClientHello length 읽기
    hello_len = int.from_bytes(body[1:4], "big")
    hello = body[4:4+hello_len]
    
    # 7. Session ID, Cipher Suites, Compression Methods 건너뛰기
    pos = 34  # 버전(2) + Random(32)
    
    # Session ID
    session_id_len = hello[pos]
    pos += 1 + session_id_len
    
    # Cipher Suites
    cipher_len = int.from_bytes(hello[pos:pos+2], "big")
    pos += 2 + cipher_len
    
    # Compression Methods
    compression_len = hello[pos]
    pos += 1 + compression_len
    
    # 8. SNI 찾기
    if pos >= len(hello):
        return None  # Extensions 없음
    
    extensions_len = int.from_bytes(hello[pos:pos+2], "big")
    pos += 2
    end = pos + extensions_len
    
    # Extensions 순회
    while pos + 4 <= end:
        ext_type = int.from_bytes(hello[pos:pos+2], "big")
        ext_len = int.from_bytes(hello[pos+2:pos+4], "big")
        pos += 4
        
        if ext_type == 0x0000:  # SNI extension
            ext_data = hello[pos:pos+ext_len]
            # Server Name List Length 건너뛰기
            server_name_list = ext_data[2:]
            # Name Type (0x00) 건너뛰기, Name Length 읽기
            name_len = int.from_bytes(server_name_list[1:3], "big")
            domain = server_name_list[3:3+name_len].decode("idna")
            return domain.lower()
        
        pos += ext_len
    
    return None  # SNI 없음

3. 정책 엔진 핵심 로직 (proxy/policy.py)
================================================================================

정책 결정 함수 (파이썬 의사코드):

def decide(sni: str | None, rules: dict[str, Rule], default_action: str) -> Decision:
    # 1. SNI가 정책 규칙에 있는지 확인
    if sni:
        sni_lower = sni.lower()
        if sni_lower in rules:
            rule = rules[sni_lower]
            return Decision(
                action=rule.action,  # "allow" or "block"
                reason=rule.reason
            )
    
    # 2. SNI가 없거나 정책에 없으면 기본 정책 적용
    if sni is None:
        return Decision(
            action=default_action,
            reason="SNI 없음: 기본 정책 적용"
        )
    
    # 3. 알 수 없는 SNI
    return Decision(
        action=default_action,
        reason="알 수 없는 SNI: 기본 정책 적용"
    )

업스트림 연결 검증:
- 업스트림 주소는 로컬호스트만 허용 (127.0.0.1, localhost, ::1, test-server)
- 포트는 1~65535 범위
- 정책 파일에서 하드코딩된 주소만 사용 (동적 연결 불가)

6. 프록시 핵심 로직 (proxy/main.py)
================================================================================

클라이언트 처리 루틴 (의사코드):

async def handle_client(client_reader, client_writer, policy, logger):
    try:
        # 1. ClientHello 수신 (TLS record 완성 대기)
        tls_record = await read_initial_tls_record(
            client_reader, 
            timeout=5.0
        )
        
        # 2. SNI 추출 및 정책 판단
        try:
            metadata = parse_client_hello(tls_record)
            sni = metadata.sni
        except ClientHelloParseError as e:
            # 파싱 오류 로그
            log_connection(
                sni=None,
                decision="block",
                error=str(e),
                elapsed_ms=...
            )
            client_writer.close()
            return
        
        # 3. 정책 결정
        decision = policy.decide(sni)
        
        # 4. 정책에 따른 처리
        if decision.action == "allow":
            # 업스트림 연결
            upstream_reader, upstream_writer = await asyncio.open_connection(
                policy.upstream_host,
                policy.upstream_port
            )
            
            # 최초 ClientHello 전송
            upstream_writer.write(tls_record)
            await upstream_writer.drain()
            
            # 양방향 스트림 중계
            await relay_streams(
                client_reader, client_writer,
                upstream_reader, upstream_writer
            )
        else:
            # block: 연결 종료
            client_writer.close()
            
    except Exception as e:
        # 오류 로그
        log_connection(
            error=str(e),
            decision=decision.action
        )
    finally:
        # 로그 작성
        log_connection(...)

8. SNI 기반 필터링의 한계
================================================================================

한계 1: SNI 부재
- IPv6 또는 특정 설정에서 SNI 없이 연결 가능
- 대응: 기본 정책 적용

한계 2: 불분명한 SNI
- 동일 IP에서 여러 도메인 호스팅 시 구분 불가
- 대응: IP 기반 정책과 병행

한계 3: ECH (Encrypted Client Hello)
- TLS 1.3의 ECH 확장은 ClientHello 전체를 암호화
- SNI 기반 필터링 완전 회피 가능
- 대응: QUIC/HTTP/3 정책으로 대체

한계 4: QUIC/HTTP/3
- UDP 기반이므로 SNI 추출 자체 불가
- 대응: 애플리케이션 계층 정책 필요

한계 5: 암호화 DNS (DoH, DoT)
- DNS 요청 자체 암호화되어 도메인 정보 숨김
- 대응: 네트워크 기반 필터링 무효화

한계 6: VPN/프록시 우회
- 외부 프록시를 통한 연결이면 SNI 추출 불가
- 대응: VPN/프록시 탐지 필요

결론:
SNI 기반 필터링은 단독으로는 효과적이지만, 
다양한 우회 기법에 대응하려면 
다층 방어(DNS, IP, DPI, 애플리케이션 계층) 필요

10. 사용 방법
================================================================================

환경 설정:
  python -m venv .venv
  source .venv/bin/activate
  pip install -r requirements.txt

인증서 생성:
  ./scripts/generate-cert.sh

로컬 실행:
  터미널 1: python -m server.https_server
  터미널 2: python -m proxy.main
  터미널 3: ./scripts/test-allowed.sh

Docker 실행:
  docker-compose up

자동 테스트:
  python -m pytest -v

로그 확인:
  cat logs/proxy.jsonl | jq .
