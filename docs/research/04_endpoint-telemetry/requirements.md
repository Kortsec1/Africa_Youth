기준일: 2026-11-02

## 판정

PoC 소스는 존재하며 기본 수집·수정의 과거 실행 증거가 있다. 학생용 보고서에서 코드 설명이 부족하고 README 검증상태가 오래되어 이번에 보완했다. 이 작업은 문서 정합성 수정이며 코드 재빌드/새 실험은 하지 않았다. 전체 실험100% 완료 판정은 부적절하다.

## 과업별 실제 충족 수준

1. Clipboard/Foreground API 조사: 조사/근거 존재. 앱별 동작 검증 전체 완료는 아님.
2. 프로세스 수집 조사: WMI/ETW 최소 비교와 코드 수정 효과 확인. PID 재사용/부하 미검증.
3. Event Log/ETW 활용 조사: 조건/방법 비교와 감사 상태, ETW 프로세스 실험 있음. Security 이벤트 생성/파일ETW 미수행. 조사 과업과 모든 소스의 구현 완료는 다름.
4. PoC 구현: 실제Program.cs와 기본 수신 확인 있음. 창/탭 정량 비교 미완료.
5. 시나리오 실험: C1/C3/P1/F1 자동시험 및 AI 보조시험 있음. W1 정량/W2/P3 전용 검증 및 엄격한 X1X2 통합대조는 부족.
6. 한계 정리: 현 증거 기준 완료. 불확실성을 숨기지 않고 미수행 기록.

## 완료 기준별 재검토

- 소스 활성/실패 실제 로그: 있음. Clipboard 조회 실패/WMI 필터/정책 차단 구분.
- C1/C3: 실제 로그 및 수행 보고 있음. 조작별 정답시각 독립 기록 없음.
- W1: 기존전환수신은 확인.5왕복 정량 미수행, 실행차단 명시.
- W2: 통제 탭시험 미수행, 실행차단 명시.
- P1: 관리자 자동test PID23868 시작/종료 확인.
- P3: 초기process_snapshot 존재와 별개로, 사전브라우저 시작·snapshot·실제start를 정답 대조한 전용시험 미수행. 전용정답 미확보 및 추가실행 보류.
- X1/X2: 설치앱 A/B는 미paste/paste미전송 비교. Chrome확장도 paste/미paste. 전송은 별도 수동화면. 원래 전송/미전송 통합쌍 시험을 완료한 것으로 처리 불가. 구성요소별 보조증거만 존재.
- EventLog/ETW 문헌/실측 구분: 있음.
- 과거macOS 미검증 상태 갱신: 과거Windows 성공 및 현재차단 분리. README 이번갱신.
- 유출탐지 완성 과장 배제: 유지.

## 문서 보완 이력

학생용 보고서 질문형 제목을 서술형으로 전면 변경. 코드 파일·구성요소·행번호·흐름·수정내역을1.5절에 추가. 방법별 비교1.6절, 원래실험ID 대조3.4절 추가. README 현재상태/실행안내갱신. 소스코드는 변경하지 않음.
