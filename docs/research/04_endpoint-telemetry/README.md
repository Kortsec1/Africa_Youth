# Endpoint Telemetry: Windows 실시간 사용자 행동 수집

담당: 동훈 / 실험 정리 기준: 2026-11-02 / 저장소 정리: 2026-11-03 / 과제 기준 대조: 2026-11-15

## 1. 연구 목표

**Windows 사용자 행위를 실시간으로 수집하여 기존 포렌식 아티팩트의 한계를 보완한다.**

- 클립보드 상태 변경, 활성 창 전환, 프로세스 시작·종료를 실시간으로 기록한다. 이 기록으로 AI 사용 전후의 행동 맥락을 보완한다.
- 복사와 창 전환만으로 붙여넣기·전송을 단정하지 않는다.

**현재 판정: 기본 PoC와 주요 기능 검증 완료, 일부 정량·통합 실험 미완료.** 완성된 유출 탐지 시스템은 아니다.

## 3. 기존 포렌식 아티팩트의 한계와 보완 관계

사후 아티팩트(`$MFT`, `$UsnJrnl`, LNK, JumpList 등)로 알기 어려운 부분과, 실시간 수집이 실제로 어디까지 보완했는지를 정리한다.

| 기존 아티팩트의 한계 | 실시간 수집으로 보완한 것 | 04 검증 상태 | 남는 한계 |
|---|---|---|---|
| 파일 시스템 아티팩트는 클립보드 활동을 다루지 않는다 | 클립보드 변경 시점과 데이터 형식 기록(원문은 저장하지 않음) | C1 수행. C3는 알림 1건 대조(조작별 독립 시각 없음) | 붙여넣기는 클립보드를 바꾸지 않아 알림이 오지 않는다. 복사 원문과 붙여넣기 대상은 알 수 없다 |
| USN 레코드에는 프로세스·사용자 정보가 없다 [MS-USN] | 프로세스 시작·종료와 활성 창을 같은 시간축에 기록해 시간 근접으로 연결 | P1 수행(WMI·ETW에서 같은 테스트 PID 확인) | 파일 이벤트 수집은 본체에 통합하지 않았다(F1 파일 수집 미검증). 파일을 만든 프로세스를 직접 귀속할 수는 없다 |
| 실행·열기 흔적(JumpList 등)은 어떤 창을 앞에 두고 썼는지 알려 주지 않는다 | 활성 창 전환 이벤트와 선택적 창 제목 | 기본 전환 수신 확인 | W1 5왕복 정량 대조와 W2 탭 전환은 실행 차단으로 미수행. 화면을 읽었는지는 알 수 없다 |
| 업로드(읽기만 하는 행위)는 파일 시스템에 거의 남지 않는다 | Chrome 확장의 웹 붙여넣기 이벤트, 별도 네트워크 화면에서 합성 문장 포함 확인 | 붙여넣기 1건 / 대조군 0건 | 붙여넣기부터 전송까지 한 번에 연결한 통합 대조(X1/X2)는 미완료. 서버 내부 처리는 알 수 없다 |
| 사후 기록은 덮어쓰기·순환으로 사라진다(USN 순환, LNK 덮어쓰기) | 이벤트 발생 시점에 JSONL로 보존하고 기록 번호와 해시로 정합성 확인 | 11개 JSONL 해시·기록 번호·내부 시간 정합성 확인 | 수집기가 실행 중일 때만 기록된다. 장시간·고빈도·강제 종료 경로의 누락률은 미측정 |

정리하면 실시간 수집은 **"언제 무엇을 복사했고, 어느 창과 프로세스가 함께 있었는가"**라는 맥락을 더해 준다. 그러나 **"AI로 내용을 보냈다"는 증거를 단독으로 만들지는 못한다.** 사후 아티팩트, 브라우저·네트워크 기록과 교차해야 한다.

## 4. 기술 조사

| 수단 | 역할 | 확인 범위 |
|---|---|---|
| Clipboard API | 변경 알림·형식 조회 | 실측·재시도 개선 확인 |
| WinEvent hook | 활성 창·선택적 제목 | 기본 수신, 창/탭 횟수 검증 미완료 |
| WMI Trace | 프로세스 실행·종료 | 종료 세션 필터 수정 및 최소 검증 |
| Security Event Log | 감사 조건에 따른 기록 | 감사 설정·접근 확인, 생성 대조 미수행 |
| ETW | 프로세스 사건의 독립 추적 | 최소 시작/종료 비교 완료 |
| Chrome 보조 확장 | 웹 paste 이벤트 | 붙여넣기 1건 / 대조 0건 확인 |

방법별 비교와 선택 이유는 [results.md §1.6](results.md)에 있다. 공식 문서 기준 판정은 [자료 기반 판정과 한계](evidence-based-reasoning.md)에 있다.

## 6. 실행 환경 제약

- 현재 개인 PC에는 Smart App Control 차단 증적이 있어 실행을 재현하는 데 제약이 있다. 정책 우회 지시는 제공하지 않는다.
- 원시 자료는 로컬에 보존한다. 저장소에는 공유용 요약과 합성 실험의 선택 필드만 게시한다.
- 관련 코드와 기록은 이 폴더에만 모았다. 다른 팀원의 연구 문서는 변경하지 않는다.
