# 공유용 실험 증거와 보존 범위

## 1. 게시 자료의 성격

이 폴더의 *.projected.jsonl은 원시 로그에서 선택한 필드만 남긴 **공유용 파생 자료**다. 원시 JSONL과 동일하지 않으며, PoC의 원래 JSONL 스키마를 그대로 재현한 파일도 아니다. projection=true와 실험별 이름을 추가했다. UTF-8 JSON으로 다시 저장하면서 시각 표기·필드 순서가 달라질 수 있다.

장치명, 사용자SID, 로컬 절대경로, 창 제목, 다른 프로그램 목록, 브라우저 탭/문서 식별자는 제외했다. 원본·실행파일·ETL·전체화면·진단 원문은 로컬에 보존하고 저장소에 게시하지 않았다. source_sha256은 원본 식별 기준이며 원본 자체를 공개한 것은 아니다.

## 3. 추가 검증 요약

- 관리자 읽기전용 조회 당시 프로세스 생성·종료·파일시스템 감사 없음. Security채널은 활성.
- 최근14일 중 최신1000건의 Security 표본에4688/4689/4663 없음. 전체 이력 부재로 해석하지 않음.
- 전체서비스 조회 성공했으나 기본 Sysmon서비스/경로와 표준채널 없음. 이름변경 구현이나 과거설치 전체를 배제하지 않음.
- 로그11개 해시가 기존목록과 일치하고,run_id혼합/기록번호중복/공백/내부시간역전 없음. OS단계 손실0을 의미하지 않음.
- 메모장 합성파일 열기·편집·저장을 UI로 수행하고 파일 읽기로 확인. 해당 시점 수집기 미실행으로 파일이벤트 수집 증거는 아님.
- 10실행의 브라우저초기목록147관측은 수집전 생성된 프로세스였고 같은PID의 새시작이벤트와 구분됨. 반복관측이므로147개 독립실험이 아니며 P3통제실험 완료는 아님.
- 네트워크 전송은 사용자 제공 화면의 별도 수동사례. 원시HAR/동일request_id 자료 미확보. 화면은 요청 맥락값/개인정보 검토상 저장소에 게시하지 않음.

## 4. 증거 사용 제한

공유본에서 빠진 필드나 원시파일은 외부 검토자가 직접 확인할 수 없다. 따라서 보고서의 모든 주장에 대한 완전한 재현자료라고 설명하지 않는다. 원본이 필요한 팀 검토는 승인된 제한 공유로 별도 진행한다. 사용자원문 수집·해시 기반 내용추적·송신자동수집 기능은 추가하지 않았다.
