# 실험 절차서 (채원 / Windows 11 Home 25H2 / 브라우저만 사용)

## 0. 준비

1. 새 Chrome(또는 Edge) **게스트/별도 프로필**을 쓰고, 다른 탭·메신저·동기화 앱은 닫는다. DNS 캐시에는 PC 전체의 조회가 섞이므로 개인 사용을 최소화한다.
2. 브라우저의 **보안 DNS(DoH) 설정을 확인**하고 기록한다. (Chrome: 설정 → 개인정보 및 보안 → 보안. Edge도 비슷한 항목이 있다.) 켜져 있으면 Windows DNS 캐시에 기록이 거의 안 남을 수 있다. 이것이 실험 6의 핵심이다.
3. 브라우저 이름과 버전, Windows 빌드(`winver`), 관리자 권한 사용 여부를 기록한다.
4. `poc/` 폴더의 스크립트를 로컬에 두고(인터넷에서 내려받은 파일이면 `Unblock-File`) PowerShell에서:
   ```
   Set-ExecutionPolicy -Scope Process RemoteSigned
   .\collect_network.ps1 -Label test -DurationSec 30
   ```
   스크립트가 막히거나 오류가 나면 그대로 results.md의 한계로 기록한다. 보호 기능을 끄지는 않는다.
5. (선택, 관리자) DNS-Client 로그 활성화: `wevtutil sl Microsoft-Windows-DNS-Client/Operational /e:true`

## 1. 매 실행 공통 순서

1. (관리자) `ipconfig /flushdns` 로 DNS 캐시 비우기. 권한이 없으면 못 했다고 기록한다. **이 명령이 끝난 뒤에** 3번을 실행한다. 두 줄을 한꺼번에 붙여넣으면 순서가 꼬일 수 있으니 한 줄씩 실행한다.
2. 브라우저를 완전히 종료하고 새로 연다. (브라우저 자체 DNS 캐시 때문)
3. 수집 시작: `.\collect_network.ps1 -Label <시나리오_회차> -DurationSec 180`
4. **기록표에 행동 시작 시각을 적고** 시나리오 행동을 수행한다.
5. 행동 종료 시각을 적고, 수집이 끝날 때까지 기다린다.

## 2. 시나리오

각 시나리오를 3~5회 반복한다. 횟수는 results.md에 그대로 적는다.

| ID | 행동 | 확인하려는 것 |
|---|---|---|
| S0 | 브라우저 닫고 2분 대기 | 배경 통신 기준선 |
| S1 | chatgpt.com 첫 화면 열기 (입력 없음) | 접속 흔적 |
| S2 | chatgpt.com에서 합성 문장 입력·전송 (테스트 계정, 사용 불가하면 "미수행"으로 기록) | S1과 네트워크 기록이 구분되는가 |
| S3 | claude.ai, gemini.google.com 각각 열기 | 서비스별 도메인 특성 |
| S4 | 일반 사이트 (뉴스, 검색, 영상) 열기 | AI 서비스와 비교, 오탐 후보 |
| S5 | 검색 결과에 AI 사이트 링크가 보이는 화면만 열기 (클릭 안 함) | 오탐 |
| S6 | S1을 보안 DNS 켬/끔 각각 수행 | DoH가 탐지에 주는 영향 |
| S7 | S1을 시크릿 창에서 수행 | 시크릿 모드 영향 |
| S8 | S1 직후 10분간 수집 유지 | DNS 캐시 잔존 시간 |

## 3. 행동 기록표 (정답 시각)

| run_id | 시나리오 | 행동 시작 | 행동 종료 | 메모(DoH 여부, 오류 등) |
|---|---|---|---|---|

시각은 PC 시계 기준으로 초 단위까지 적는다. 이 표가 있어야 로그의 어느 부분이 어느 행동인지 연결할 수 있다.

## 4. 보내줄 것

- `out/*.jsonl` 파일들과 행동 기록표
- 환경 정보 (OS 빌드, 브라우저 버전, 보안 DNS 설정, 권한)
- 오류가 났다면 오류 메시지 전문

보내기 전에 로그를 한 번 훑어서, 실험과 무관한 개인 사이트 도메인이 있는지 확인한다. 있으면 그 줄을 지우고 지웠다고 알려준다.
