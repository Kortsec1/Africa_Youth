# 실험 결과

## 1. 실험 환경
운영체제: Windows
브라우저: Google Chrome
브라우저 버전: 157.0.0000.00
프로필: Profile 4
분석 대상: Chrome History 및 Cache
캐시 파일 경로: Profile 4\Cache\Cache_Data

## 2. 실험 목적
Windows 환경에서 ChatGPT 웹 서비스를 이용할 때 Chrome History 및 Cache에 남는 흔적을 조사하고, 서비스 접속 기록과 실제 질문 전송 행위를 구분할 수 있는지 확인한다.

## 3. 실험 과정
1. Chrome 브라우저의 버전과 Profile 4 경로를 확인하고 분석 환경을 기록하였다.
2. Chrome History에서 chatgpt.com을 검색하여 ChatGPT 방문 기록과 페이지 제목, 표시 시각을 확인하였다.
3. Chrome의 Cache_Data 폴더에서 f_000001 파일의 크기와 수정 시각을 확인하였다.
4. 테스트 질문 AI 포렌식 실험 EXP-04 테스트 질문 2026-11-15를 전송하고 질문 전송 시각과 응답 표시 시각을 기록하였다.
5. 질문 전송 이후 Chrome History를 다시 확인하여 테스트 문구가 포함된 페이지 제목과 방문 기록을 관찰하였다.
6. History와 Cache에서 확인한 정보를 비교하고, 각 기록으로 입증할 수 있는 범위와 한계를 검토하였다.

## 4. 실험 결과
4.1 Chrome History 분석
- chatgpt.com 관련 방문 기록이 확인되었다.
- 페이지 제목으로 ChatGPT, AI 포렌식 실험 Dabao, AI 포렌식 실험 EXP-04 테스트 질문 2026-11-15가 표시되었다.
- History 화면에서 2026년 11월 15일 오후 8시 45분으로 표시된 기록 3개를 확인하였다.
- 테스트 질문 전송 시각은 오후 8시 37분, 응답 표시 시각은 오후 8시 45분으로 기록하였다.

4.2 Chrome Cache 분석
- Profile 4\Cache\Cache_Data 경로에서 f_000001 파일을 확인하였다.
- 파일 크기는 62,086 bytes(약 60.6 KB)였다.
- 파일 수정 시각은 2026년 3월 23일 오후 5시 16분 25초였다.
- 파일의 크기와 수정 시각은 확인했으나 내부 콘텐츠와 ChatGPT 사용 행위의 연관성은 검증하지 않았다.

4.3 종합 결과

Chrome History에서 ChatGPT 관련 방문 기록과 테스트 문구가 포함된 페이지 제목을 확인하였다. 이를 통해 AI 서비스 접근 및 관련 페이지 기록의 존재를 확인할 수 있었다.

그러나 History의 페이지 제목과 방문 시각만으로 질문의 실제 전송 성공 여부를 독립적으로 입증할 수는 없다. 또한 Cache 파일의 메타데이터만으로 질문 내용이나 파일 업로드 여부를 확인할 수 없었다.

## 5. 확인된 한계
- History에 기록된 페이지 제목은 질문 전송 행위를 뒷받침하는 단서가 될 수 있지만, 서버에 질문이 성공적으로 전달되었다는 사실까지 단독으로 입증하지는 못한다.
- Cache 파일의 이름, 크기 및 수정 시각만으로 해당 파일의 출처나 내부 콘텐츠를 확정할 수 없다.
- f_000001의 수정 시각은 2026년 3월로, 2026년 11월에 수행한 질문 전송 실험과의 직접적인 연관성은 확인되지 않았다.
- Cache 내부 콘텐츠 분석과 파일 업로드 실험은 아직 완료하지 않았다.
- 브라우저 설정, 캐시 정책 및 기록 보존 상태에 따라 수집 가능한 흔적이 달라질 수 있다.
- 현재 결과는 Chrome 웹 환경을 중심으로 하며, Claude, Gemini 및 데스크톱 AI 애플리케이션과의 비교는 추가 조사가 필요하다.

## 6. 추가 연구 사항
- 질문 전송 전후의 브라우저 아티팩트를 비교하여 단순 접속과 질문 전송 사이의 차이를 조사한다.
- 개인정보가 없는 테스트 파일을 업로드하고 History 및 Cache에서 확인할 수 있는 흔적을 분석한다.
- 캐시 파일의 내부 콘텐츠를 확인할 필요가 있는 경우 원본을 보존하고 분석용 복사본을 이용한다.
- Chrome과 Edge의 History 및 Cache 구조를 비교한다.
- Claude와 Gemini 웹 환경에서도 동일한 실험 시나리오를 적용하여 결과를 비교한다.
- 데스크톱 AI 애플리케이션에서 생성되는 로컬 흔적과 웹 환경의 차이를 조사한다.
- 서비스 접속, 질문 전송, 파일 업로드에 대해 각 아티팩트가 제공하는 증거 수준과 기술적 한계를 정리한다.
