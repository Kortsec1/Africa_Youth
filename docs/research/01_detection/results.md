# 상관분석 실험 결과 및 한계

## 1. 실험 환경 및 목적

- 수행 주체: Codex 실행 환경
- Python: 3.14.6
- 외부 패키지: 없음
- 데이터: 직접 작성한 가상 이벤트
- 정책: demo-v1
- 기본 시간 범위: 60초
- 반복 방문 기준: 3회

사용자 PC에서는 아직 재실행하지 않았다.
실제 Windows 로그 수집이나 AI 서비스 사용 실험은 수행하지 않았다.

목적은 규칙 R01~R05의 출력이 사전에 정의한 시나리오와 일치하는지 확인하는 것이다.

## 4. 해석 및 한계

정의한 가상 사례에서 예상 판정과 코드 출력이 일치했다.
이 결과는 실제 환경의 탐지율·오탐률 또는 업로드 탐지 성공을 의미하지 않는다.

- 실제 데이터의 수집 오류·식별자 매핑·시각 오차는 검증하지 않았다.
- 새로고침·자동 방문은 R03에도 일치할 수 있다.
- R02는 시간·장치·사용자 관계만 평가하며 파일 전송을 입증하지 않는다.
- 입력 스키마 전체 검증과 성능 최적화는 아직 구현하지 않았다.
- 연결 조건별 비교 실험은 아래 추가 실험에 별도로 기록했다.

## 추가 실험: 상관분석 조건별 오연결 비교

### 목적과 환경

- 수행: Codex 실행 환경, Python 3.14.6, 외부 패키지 없음
- 입력: comparison_cases.json의 가상 시나리오 9개
- 정책: demo-v1, 기존 analyze.py 사용
- 대상: R02에 해당하는 파일 읽기 후 미승인 서비스 접근 정황
- 사용자 PC에서의 재현 여부: 별도 확인 필요

비교 방식:
1. time: 승인 정책 필터 + 절대 시간 차이
2. identity: time 조건 + 장치·사용자 일치
3. ordered: 기존 analyze.py의 R02 결과, 발생 순서까지 검사

앞의 두 방식은 일부 조건을 제거한 대조 분석이다.
파일·방문 유형과 승인 정책은 동일하게 두어 연결 조건의 차이를 비교한다.

### 입력과 정답

각 시나리오는 기존 sample_events.json의 evt-001과 evt-003을 복사한 독립 실험이다.
방문 시각·장치·사용자·서비스를 comparison_cases.json에 따라 변경한다.
서로 다른 시나리오 사이의 이벤트는 연결하지 않는다.

related는 실제 로그에서 알아낸 사실이 아니라 실험 작성자가 미리 설정한 평가 정답이다.
여기서 true는 '관련된 파일 읽기 후 미승인 서비스 접근으로 설정한 사례'를 뜻한다.
승인된 서비스 사례는 이 평가 대상에서 제외되는 음성 사례로 정의했다.
업로드 성공 여부를 정답으로 사용하지 않는다.

정답이 있는 8건(양성 2건, 음성 6건)을 집계한다.
사용자 미확인 C09는 정답을 null로 두고 집계에서 제외하며, 예측과 R05 출력은 보존한다.
C06은 같은 사용자의 무관한 작업이 우연히 인접했다는 설정이다.
이 배경 사실은 분석기에 입력하지 않으므로 관찰 필드만으로 구별할 수 없다.

### 재현 명령

poc/ 폴더에서 실행:


### 실제 실행 결과

TP: 예상한 관련 정황 탐지 / FP: 잘못 연결 / TN: 음성 사례 비탐지 / FN: 양성 사례 누락

| 시간 범위 | 방식 | TP | FP | TN | FN |
|---|---|---:|---:|---:|---:|
| 30초 | 시간만 | 0 | 5 | 1 | 2 |
| 30초 | 시간+식별자 | 0 | 3 | 3 | 2 |
| 30초 | 시간+식별자+순서 | 0 | 1 | 5 | 2 |
| 60초 | 시간만 | 1 | 5 | 1 | 1 |
| 60초 | 시간+식별자 | 1 | 3 | 3 | 1 |
| 60초 | 시간+식별자+순서 | 1 | 1 | 5 | 1 |
| 300초 | 시간만 | 2 | 5 | 1 | 0 |
| 300초 | 시간+식별자 | 2 | 3 | 3 | 0 |
| 300초 | 시간+식별자+순서 | 2 | 1 | 5 | 0 |

### 해석 및 한계

- 60초 조건에서 식별자와 순서를 추가하자 오연결은 5건에서 1건으로 감소했다.
- C06은 모든 조건을 충족해도 오연결로 남았다. 시각과 식별자 일치만으로 인과관계를 입증할 수 없다.
- 시간 범위를 늘리자 이 데이터의 양성 사례 누락은 감소했다.
- 이번 음성 사례는 모두 짧은 시간 차이로 구성되어 있어 넓은 시간 범위에서 오탐이 늘어나는 현상은 검증하지 못했다.
- C09는 R05로 정보 부족을 표시했다. 이를 정상 판정이나 정탐으로 계산하지 않았다.
- 300초가 최적이라는 결론을 내릴 수 없다. 사례를 확대해야 한다.
- 수작업 가상 사례의 결과이며 실제 환경의 탐지 성능이나 데이터 유출 여부를 입증하지 않는다.

### 후속 연구

장시간 범위에 들어오는 무관한 이벤트와 다수 사용자·서비스 사례를 추가한다.
실제 수집 로그를 연동할 때는 시각 오차와 식별자 매핑을 별도로 검증한다.
