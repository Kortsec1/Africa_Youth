# 상관분석 실험 결과 및 한계

## 1. 현재 상태

현재 연구 범위와 기초 기술 조사, 실험 계획을 작성했다.
PoC 구현과 실험 실행은 아직 수행하지 않았다.

- 실험 환경: 미구성
- 가상 이벤트 데이터: 미작성
- 상관분석 코드: 미구현
- 실험 실행: 미수행
- 오탐·미탐 평가: 미수행

기술 조사와 계획은 README.md에 기록한다.
이 문서에는 실제로 수행한 실험 결과만 추가한다.

## 2. 예정된 첫 실험

### 목적

시간 조건만으로 이벤트를 연결했을 때와
장치·사용자·순서 조건을 추가했을 때의 결과를 비교한다.

### 입력 계획

- 같은 장치·사용자의 파일 접근과 미승인 AI 접근
- 서로 다른 장치 또는 사용자의 이벤트
- 승인된 AI 서비스 접근
- 시간 범위를 벗어난 이벤트
- 연결에 필요한 정보가 누락된 이벤트

입력은 직접 작성한 가상 이벤트이며 실제 수집 로그가 아니다.
시나리오별 예상 판정은 코드 실행 전에 작성한다.

### 비교 계획

1. 시간 조건만 적용한 결과
2. 시간과 장치·사용자 조건을 적용한 결과
3. 시간과 장치·사용자·순서 조건을 적용한 결과

각 결과에서 잘못된 연결, 놓친 시나리오와 판단 불가 사례를 확인한다.

## 3. 실험 후 기록할 항목

- 실험 ID 및 실행일
- 실행 환경과 도구 버전
- 사용한 코드·규칙·입력 데이터 버전
- 실험 목적과 예상 판정
- 실행 명령 및 재현 절차
- 실제 출력과 관찰 결과
- 예상 판정과 실제 출력의 차이
- 오탐·미탐 원인
- 기술적 한계와 추가 연구 사항

## 4. 결과 해석 원칙

가상 데이터 실험은 설정한 시나리오에서
구현과 규칙이 의도대로 동작하는지 검증한다.

이 결과만으로 실제 Windows 환경의 탐지율이나
오탐률을 입증했다고 설명하지 않는다.

파일 접근과 AI 서비스 접근을 연결했더라도
파일 업로드나 데이터 유출을 확인한 것으로 기록하지 않는다.
